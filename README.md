# 📊 Application de Recherche Opérationnelle
Application de bureau interactive développée en Python (Tkinter, Matplotlib) implémentant des algorithmes de graphes et d'optimisation (Dijkstra, Kruskal, Welsh-Powell, Bellman-Ford, Ford-Fulkerson, Simplexe).

*Projet réalisé dans le cadre de ma formation d'ingénieur en Génie Réseaux et Télécommunications à l'EMI.*
